# DVCon Europe 2026 paper — artifact index

**The submission artifact is `camera_ready.docx`.** Nothing else in this
directory should be uploaded to the submission system.

## Authoritative source

| File | Role |
|---|---|
| `camera_ready.md` | **Source of truth.** Edit this; never edit the generated files. |
| `camera_ready.docx` | **Submission artifact.** Generated by `build_docx.py`, styled to the DVCon Europe template. |
| `camera_ready.pdf` | Review copy, converted from the `.docx`. Not the submission format. |
| `camera_ready.tex` | LaTeX rendering, generated by `build_tex.py`. Single-column A4 with 0.75in margins, matching the DOCX. **Not compiled here** — no LaTeX toolchain is installed; `build_tex.py` runs static checks instead. |
| `camera_ready_latex.zip` | **Upload this to Overleaf**, not the bare `.tex`. Contains `main.tex` plus `figures/*.pdf`. The `.tex` alone fails with `File 'figures/...' not found`. |

Regenerate after any edit to `camera_ready.md`:

```bash
python3 build_docx.py camera_ready.md camera_ready.docx
python3 build_tex.py  camera_ready.md camera_ready.tex   # fails loudly on a bad table/citation/figure
soffice --headless --convert-to pdf --outdir . camera_ready.docx
```

Rebuild the Overleaf bundle after changing the `.tex` or any figure:

```bash
rm -f camera_ready_latex.zip && mkdir -p /tmp/b/figures
cp camera_ready.tex /tmp/b/main.tex
cp figures/figure1_flow_comparison.pdf figures/figure2_flows_combined.pdf \
   figures/figure4_coverage_closure.pdf /tmp/b/figures/
(cd /tmp/b && zip -qr "$OLDPWD/camera_ready_latex.zip" main.tex figures)
```

The figure PDFs are vector, regenerated from the SVGs with headless Chrome
(`--print-to-pdf`, `@page size` set to the SVG's own pixel dimensions so the
aspect ratio is preserved). LaTeX prefers `.pdf` over `.png`, so the PDFs win
wherever both exist; the PNGs remain because `build_docx.py` uses them.

## Supporting files

- `figures/` — figures referenced by the paper. `figure1_architecture`,
  `figure2_flows_combined`, `figure4_coverage_closure` are the three used;
  the standalone `figure2_simulation_flow`/`figure3_emulation_flow` are the
  panels that were merged into `figure2_flows_combined`.
- `dm_divergence.sh` — regenerates the debug-module divergence figure quoted
  in Section IV-A (1102 of 3333 shared lines, 33%). Run from the repository
  root.
- `tpc_review_plan.md` — the structured response to the abstract-stage TPC
  review. Working notes, not part of the paper.
